# Blue Board

Job, crew and profit tracking for contractors. The same `index.html` runs as the website
(https://getblueboard.com, GitHub Pages from `main`) and as the iPhone app (Capacitor).
Two people work on this repo, each with their own Claude Code. Repo is **public**: never
commit secrets, API keys, passwords, personal emails or device IDs.

Note: README.md is out of date. Data now lives in Supabase (accounts, companies, sync),
not only on the device.

## Layout
- `index.html` – the whole app: HTML, CSS, JS in one file, no build step. Large; read it in
  parts and search with grep rather than reading it whole.
- `doc.html` – customer-facing estimate/invoice page, generated by `scripts/build-doc.mjs`.
- `privacy.html`, `support.html` – public pages linked from the app and App Store listing.
  Update them when a feature changes what data is collected.
- `sw.js` – service worker. **Bump `VERSION`** whenever a cached file (see `SHELL`) changes.
- `vendor/` – vendored Supabase client and fonts (Manrope, DM Sans). No CDNs.
- `supabase/schema.sql` – database schema and SQL functions.
- `supabase/functions/notify` (push notifications), `supabase/functions/payments` (Stripe Connect).
- `ios/` – Xcode project (Capacitor 8, Swift Package Manager). `ios/App/App/ReceiptScan.swift`
  is a native receipt-OCR plugin.
- `www/` – build output for Capacitor (gitignored; made by `scripts/build-www.mjs`).

## Design (A2 "Electric Cobalt")
Cobalt #2D5BFF → cyan #00A8F0 gradient on money cards, main buttons and active tab; canvas
#F4F6FF; ink #10142B; 28px card corners; pill buttons; dark floating tab bar #10142B.
Manrope ExtraBold for headings and money, DM Sans for text. No Space Grotesk.
Logo is the navy "Solid Seal" stamp (`icons/logo-seal*.png`); no gradients or slogans in branding.

## Shipping: every change goes to BOTH the website and the iPhone app
Unless told otherwise:
1. Check the change works (open `index.html` locally / run the app).
2. **Website:** `git pull`, commit, push to `main`. GitHub Pages deploys in about a minute
   (`gh api repos/1cakeime/Job-Ledger/pages/builds/latest` to confirm). Bump `VERSION` in
   `sw.js` if a cached file changed.
3. **App:** `npm run sync` (builds `www/` and runs `npx cap sync ios`), then build/run from
   Xcode (`npm run ios` opens it). If Node isn't found, try `export PATH=/usr/local/bin:$PATH`.

Pushing to `main` updates the live site immediately, so make sure it works first.

## Working together
- `git pull` before starting. Tell each other before pushing big changes.
- Avoid both editing `index.html` at once; it's one file and conflicts are painful.
  For larger work, use a branch and a pull request.

## Supabase
SQL changes and Edge Function deploys are done by a person in the Supabase dashboard; Claude
has no admin access. When changing the database, update `supabase/schema.sql` and give the
exact SQL to run. Function deploys: `payments` must have Verify JWT **off**. Secrets
(APNs keys, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`) are set in the dashboard, never in code.

## Domain
getblueboard.com DNS is on Cloudflare pointing at GitHub Pages. Keep the records DNS-only
(grey cloud); proxying breaks GitHub's HTTPS certificate.
